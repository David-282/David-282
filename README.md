## Hi, I'm David 👋

Full-stack software engineer in Lagos, Nigeria, with a backend focus. I design and build the server side of web applications (APIs, databases, authentication and system architecture) and I build React interfaces to go with them, so I can take a feature from the database to the screen.

My main stack is Java (Spring Boot) and Python (FastAPI, Django, Flask), with PostgreSQL, Redis and MongoDB. I build clean, secure, well-documented systems: modular monoliths and microservices, JWT and role-based authentication, event-driven design, and APIs with full OpenAPI docs. I trained through Semicolon Africa’s software engineering program, where I built production-grade applications end to end, and I contribute to open-source Stellar ecosystem projects. I care about understanding the code I write, not just shipping it.

**What I'm good at**
- Designing REST APIs with Swagger/OpenAPI docs
- Authentication and authorization (JWT, role-based access, OTP verification)
- Modular monoliths, microservices and event-driven design
- CI pipelines and Docker-based development
- Turning requirements into PRDs, use cases and class diagrams before writing code
- Designing user friendly interface
- Connecting frontend to backend  

Open to work: backend and full-stack roles (remote, Lagos or Ogun State).

## Featured Projects

**[SoloRecord](LINK-TO-SOLORECORD-REPO)**: Medical records platform where patients decide which hospitals can access their data. Spring Boot modular monolith with JWT auth and role-based access, Redis-backed OTP verification and rate limiting, per-facility patient consent, facility onboarding with approval flow, PostgreSQL, and a GitHub Actions CI pipeline.

*In progress:* clinical records, lab results, outbreak detection from lab results, and the React frontend.

**[MediBook](LINK-TO-MEDIBOOK-REPO)**: Hospital appointment booking system built as Spring Boot microservices, with Spring Cloud Gateway, a database per service, and a Kafka-based saga that keeps auth and user registration consistent.

*In progress:* doctor, appointment, notification and analytics services.

**[FoodDash](LIVE-LINK)**: Food ordering app built with a teammate. Customers order for pickup or delivery and track status live over WebSockets; staff manage orders and the menu from a dashboard. Go (Gin), PostgreSQL, React and Tailwind.

**[ResultPortal](LINK-TO-RESULTPORTAL-REPO)**: Django REST API for university academics: role-based accounts, departments, courses and academic sessions, with JWT auth, Swagger docs and a Dockerized PostgreSQL setup. *Coming soon:* result upload and publishing.

**Stellar / Soroban**: Open-source contributions to Stellar ecosystem projects (Predictify Backend, Callora Backend, Harvest Finance and others) across TypeScript/NestJS, Rust and Spring Boot.
